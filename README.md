# Phishing URL Detector

Phishing URL Detector is a Python web application that identifies phishing and legitimate URLs using a trained ML model. Built with Flask, it provides a simple interface for real-time URL scanning.

## Features
- Detect phishing URLs in real-time
- Simple Flask web interface
- Supports URL input and batch testing
